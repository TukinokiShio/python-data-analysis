超平面的几何语言

在 d 维空间里，一个超平面写成：

wTx + b = 0
  • w 是法向量，垂直于超平面，指向正类一侧
  • b 是偏置，决定超平面离原点多远

任意点 x0 到超平面的几何距离：

r = |wTx0 + b| ⁄ ‖w‖

💡 只有 w 的方向决定超平面朝向；w 的模长只影响数值大小，不影响几何位置。这是后面「规范化」的关键依据。

函数间隔 vs 几何间隔

函数间隔 Functional Margin

γ̂i = yi ( wTxi + b )

只要 γ̂i > 0，就说明分类正确。

⚠️ 致命缺陷：把 w 和 b 同时放大 10 倍，超平面丝毫没变，函数间隔却大了 10 倍。所以它不能直接当优化目标。

几何间隔 Geometric Margin

γi = yi ( wTxi + b ) ⁄ ‖w‖

这正是点到超平面的真实距离，与 w 的缩放无关。

✅ 无论怎么缩放 w、b，几何间隔永远不变 —— 这才是我们真正想最大化的东西。

整个数据集的间隔取所有样本中最小的那个：γ = mini γi。因为一个分类器的「安全余量」，是由最危险的那个点决定的 —— 木桶效应。

🎯 一句话记住：函数间隔可以「通货膨胀」，几何间隔是「实际购买力」。SVM 要最大化的是后者。

从想法到优化问题（逐步拆解）

第 1 步写出原始目标
maxw,b　γ　=　maxw,b　mini　yi(wTxi+b) ⁄ ‖w‖
外层 max 表示「我们要最大化的对象」，内层 min 表示「一个分类器的间隔由最危险的点决定」。
第 2 步规范化（消除缩放自由度）
yi(wTxi+b) = 1　（对所有离超平面最近的点）
因为把 w、b 同乘一个正数 k，超平面不变。于是我们可以「武断地」规定最近点的函数间隔恰好等于 1 —— 这不影响解，只是让问题有唯一形式。
第 3 步改写目标
几何间隔变成 1/‖w‖　⟹　max 1/‖w‖　⟺　min ½‖w‖²
「最大化 1/‖w‖」和「最小化 ‖w‖」等价。平方是为了去掉根号方便求导，乘 ½ 是为了求导后系数恰好为 1。
原始问题
minw,b　½‖w‖²　　s.t.　yi(wTxi+b) ≥ 1,　i = 1,…,n

🎯 性质：目标函数 ½‖w‖² 是凸二次函数，约束是线性不等式 —— 这是标准的凸二次规划（QP），有唯一全局最优解，不怕局部极小。

带约束优化：拉格朗日乘子法（复习 + 应用）

先复习一般情形：求 min f(x)，满足 gi(x) ≤ 0。

L(x, α) = f(x) + Σi αi gi(x),　αi ≥ 0

对 SVM，把约束 1 − yi(wTxi+b) ≤ 0 代入：

L(w,b,α) = ½‖w‖² − Σi αi [ yi(wTxi+b) − 1 ]

💡 乘子 αi 的含义：第 i 个约束的「影子价格」—— 如果把这个约束放松一点点，目标函数能改善多少。后面会看到，只有恰好卡在边界上的点，αi 才不为 0。

对 w 和 b 求偏导（逐项展开）

① 展开拉格朗日函数
L = ½wTw − Σi αiyiwTxi − b Σi αiyi + Σi αi
把 [ yi(wTxi+b) − 1 ] 展开成三项，注意前面的负号会让括号内每一项变号。
② 对 b 求偏导
∂L/∂b = − Σi αi yi　⟹　Σi αi yi = 0
b 只出现在第二项里，一次项直接求导就是它前面的系数。这个等式稍后会成为对偶问题的一个约束。
③ 对 w 求偏导
∂L/∂w = w − Σi αiyixi　⟹　w = Σi αiyixi
½wTw 对 w 求导是 w；后面 ΣαiyiwTxi 可以看成 wT(Σαiyixi)，对 w 求导就是括号内那一项。

✨ 关键结论：最优法向量 w 是训练样本的线性组合！这直接把「求解 w（维度可能很高）」变成「求解 α（维度等于样本数）」—— 更妙的是，绝大多数 αi 最终会是 0。

把 w、b 代回，得到对偶问题

① 处理 b 项

因为 Σαiyi = 0，所以 −b Σαiyi = 0，b 整项消失。

② 处理 w 项

把 w = Σj αjyjxj 代入 Σi αiyiwTxi：

Σiαiyi (Σjαjyjxj)Txi = ΣiΣj αiαjyiyj xiTxj
注意下标：外层对 i 求和，内层对 j 求和，两个 α 都保留。
③ 处理 ½‖w‖² 项

同样代入得 ½ ΣiΣj αiαjyiyjxiTxj。

④ 合并

前两项系数正好是 −½，剩下的 Σαi 单独留下：

maxα　W(α) = Σi αi − ½ ΣiΣj αiαj yiyj xiTxj
s.t.　Σi αi yi = 0,　αi ≥ 0

🔑 只出现内积

目标函数里，样本只以 xiTxj 形式出现。这就是通往核技巧的大门。

📐 约束更简单

原始问题有 n 个不等式约束；对偶问题只有一个等式约束加一个盒子约束 αi≥0。

预测时：f(x) = Σi αiyi(xiTx) + b。新样本与训练样本之间也只做内积。

02

KKT 条件深度拆解

为什么大多数 αᵢ 是 0？支持向量到底是什么？

KKT 条件：五条逐一拆解

对于「min f，s.t. gi≤0，hj=0」的凸问题，若强对偶成立，最优解必须满足 KKT 条件：

① 原始可行性
yi(wTxi+b) ≥ 1,　ξi ≥ 0
最优解必须在可行域内 —— 每个样本都被正确分类且落在间隔外（软间隔时允许 ξ 补偿）。
② 对偶可行性
αi ≥ 0　（软间隔再加 αi ≤ C）
拉格朗日乘子必须非负 —— 这是不等式约束的标准要求。
③ 互补松弛性（最关键）
αi [ yi(wTxi+b) − 1 ] = 0
约束「不紧」时乘子为 0；乘子为正时约束必须「取等号」。这一条直接导致稀疏性。
④ 平稳性
∇wL = 0,　∂L/∂b = 0
就是上一页求出的两式：w = Σαiyixi 和 Σαiyi=0。
⑤ 等式约束
Σi αiyi = 0
来自对 b 求偏导。它保证超平面不会「偏心」地向某一类倾斜。

🎯 互补松弛性的三种情况：

  • αᵢ = 0：点在间隔外，非支持向量，删掉无影响
  • 0 < αᵢ < C：点在间隔边界上，标准支持向量
  • αᵢ = C：点落入间隔内或被错分，边界支持向量（软间隔特有）

软间隔与核技巧

当数据不再「完美可分」

软间隔：允许一点「犯规」（推导版）

动机

硬间隔要求所有点满足 yi(wTxi+b) ≥ 1。若数据线性不可分，这个约束无解。

松弛

给每个样本一个松弛变量 ξi ≥ 0，允许它「违规」：

yi(wTxi+b) ≥ 1 − ξi
目标
min　½‖w‖² + C Σi ξi
第一项要求「街道宽」，第二项要求「违规少」。C 是权重：C 大则更在意违规，C 小则更在意街道宽度。
对偶

推导后形式几乎不变，只是 αi 多了上界：

0 ≤ αi ≤ C
C 1.00
—

C → ∞：退化为硬间隔，惩罚极重，容易过拟合
C → 0：几乎不惩罚，街道极宽，容易欠拟合

核技巧：从内积到无限维

对偶问题和决策函数里，数据只以 xiTxj 的形式出现。于是我们大胆地把每个内积替换成核函数：

xiTxj　⟶　K(xi, xj) = φ(xi)Tφ(xj)

含义：先把数据映射到高维 φ 空间，在那里求内积。但核函数让我们跳过显式映射，直接算出结果。

🧮 代价对比：显式映射可能需要计算成千上万维坐标；核函数往往只需要一次几十次浮点运算的闭式表达式。哪怕 φ 是无限维的，计算量依然可控。

Mercer 条件：不是随便一个函数都能当核。它必须对应某个特征空间的内积，等价于核矩阵半正定。

映射程度

一维数据：红点在中间，蓝点在两侧 —— 一条直线永远切不开。但把 x → (x, x²) 抬到抛物线上，一条水平线就能分开。

常用核函数一览

线性核 Linear

K = xaTxb

无超参数。特征维度高、样本量大时首选。可解释性好（能直接读出 w）。

多项式核 Poly

K = (γxaTxb + r)d

能学出多项式形状的边界。d 越大越复杂，数值上容易不稳定。

高斯 RBF 核 ⭐

K = exp(−γ‖xa−xb‖²)

最常用。对应无限维特征空间，可拟合任意复杂边界。

γ 的直觉：高斯「小灯泡」的半径

γ 很大 → 每个样本影响范围极小 → 边界绕来绕去、围着每个点画圈 → 过拟合
γ 很小 → 影响范围很大 → 边界非常平滑，接近线性 → 欠拟合

Sigmoid 核

K = tanh(γxaTxb + r)

与神经网络有历史渊源，但不总是满足 Mercer 条件，实践中较少使用。

案例 ⑤：信用卡欺诈检测（不平衡数据）

数据：信用卡交易 · 284,807 笔 · 492 笔欺诈（占比 0.172%）· 30 个特征（PCA 降维后的 V1–V28 + Time + Amount）

⚠️ 难点：极端类别不平衡

若直接用标准 SVM，模型会倾向于把所有样本都预测为「正常」，准确率高达 99.8% 但欺诈一个都抓不到。

🔧 应对策略

  • 给少数类更大的 class_weight（如 100:1）
  • 用 SMOTE 过采样少数类
  • 评价指标改用 Recall / F1 / AUC-PR，而非准确率
  • 先用 随机欠采样 把数据降到 1 万条以内，再用 RBF SVM

💡 为什么用 PCA 后的 V1–V28？

原始交易特征涉及隐私，且维度高、相关性复杂。PCA 降维既保护隐私，又让 SVM 训练更快、更稳定。

案例总结：什么场景选 SVM？

✅ SVM 的「甜区」

  • 高维小样本（基因、文本）：n ≪ d 时表现突出
  • 类别边界复杂：RBF 核能捕捉非线性结构
  • 需要强理论基础：有泛化误差上界保证
  • 数据量中等（几千到几万）：训练时间可接受

⚠️ 不适合 SVM 的场景

  • 超大数据（百万级）：O(n²) 训练复杂度难以承受
  • 需要概率输出：原生 SVM 只给类别，需额外校准
  • 特征解释性要求高：非线性核下 w 难以解释
  • 极端不平衡 + 无调参：容易退化为「全预测多数类」

🔧 实践流程建议： ① 先标准化特征（SVM 对尺度敏感）； ② 用线性核快速 baseline； ③ 若欠拟合，换 RBF 核，用 GridSearchCV 对数搜索 C ∈ [1e-3, 1e3]、γ ∈ [1e-4, 1e1]； ④ 处理类别不平衡（class_weight / SMOTE）； ⑤ 与树模型对比，选综合指标最优者。

✍️ 手算一个完整的对偶求解

数据：x1 = (1, 1), y1 = +1　 x2 = (−1, −1), y2 = −1　（硬间隔，C 充分大）

① 写出对偶问题

maxα Σαi − ½ΣΣ αiαjyiyjxiTxj　s.t. Σαiyi=0, αi≥0

② 计算三个内积

x1Tx1 = 1+1 = 2　 x2Tx2 = 1+1 = 2　 x1Tx2 = −1−1 = −2

③ 代入目标函数

ΣΣ αiαjyiyjxiTxj = 2α1² + 2α2² + 4α1α2

⟹ W(α) = α1+α2 − α1² − α2² − 2α1α2

④ 利用等式约束消元

α1(+1) + α2(−1) = 0　⟹　α1 = α2 = α

W(α) = 2α − 4α²

⑤ 求极值

dW/dα = 2 − 8α = 0　⟹　α = 1/4

两个点都是支持向量 ✔

⑥ 还原 w 和 b

w = Σαiyixi = ¼(1,1) + ¼(1,1) = (½, ½)

b = y1 − wTx1 = 1 − (½+½) = 0

⑦ 结果

决策边界：½x + ½y = 0　⟺　x + y = 0

间隔宽度：2/‖w‖ = 2/√0.5 = 2√2 ≈ 2.828

怎么真正求解？—— SMO 算法

对偶问题是一个 n 个变量的二次规划。当 n 很大时（比如几万），通用 QP 求解器会非常慢。SMO（Sequential Minimal Optimization） 的思路极其巧妙：

🎯 核心思想：每次只挑两个 α 来优化，其余全部固定。

为什么是两个而不是一个？因为等式约束 Σαiyi=0 的存在，单独改一个 α 会立刻违反约束。改两个则刚好可以保持平衡。

两个变量固定其余的，就变成了：

一个只含两个变量、带区间约束的一元二次函数 —— 有解析解，一步就能算出最优值！

⚡ 为什么快：每次迭代只涉及两个变量，不需要存储整个核矩阵（可以用缓存），每步都有解析解，无需数值优化。配合「启发式选择最违反 KKT 的变量对」，通常几十到几百次迭代就收敛。

SVM 的优缺点与常见坑

✅ 优势

  • 理论扎实：基于结构风险最小化，有泛化误差上界保证
  • 凸优化：全局最优解，不受初始化影响
  • 稀疏性：只有支持向量参与预测，模型存储和推断都高效
  • 核方法灵活：能处理高维、非线性问题
  • 在小样本、高维数据（如文本分类）上表现优异

⚠️ 局限

  • 大数据慢：训练复杂度约 O(n²)~O(n³)，n 到十万级就很吃力
  • 调参敏感：C 和 γ 对结果影响巨大，需要仔细交叉验证
  • 概率输出难：原生 SVM 不直接给出概率（需额外 Platt 校准）
  • 可解释性弱：非线性核下很难解释「为什么这么分」
  • 对特征缩放非常敏感，必须先标准化

🔧 实践建议： ① 一定要先做特征标准化（StandardScaler）； ② 先用线性核做 baseline； ③ 用 GridSearchCV 在 C ∈ [1e-3, 1e3]、γ ∈ [1e-4, 1e1] 上对数搜索； ④ 样本量超过 10 万时，优先考虑线性 SVM（LinearSVC）或换用梯度提升树。

一页纸总结

直觉

在所有能分开的线里，选街道最宽的那条。街道宽度由支持向量决定。

原始问题

min ½‖w‖²
s.t. yᵢ(wᵀxᵢ+b) ≥ 1

对偶问题

max Σαᵢ − ½ΣΣαᵢαⱼyᵢyⱼxᵢᵀxⱼ
s.t. Σαᵢyᵢ=0, 0≤αᵢ≤C

三个关键洞察

① w = Σαᵢyᵢxᵢ —— 解是样本的线性组合
② KKT ⟹ 稀疏性 —— 只有支持向量 αᵢ>0
③ 只出现内积 ⟹ 核技巧 —— 通往非线性

两个超参数

C：间隔宽度 vs 分类错误的权衡
γ（RBF）：单个样本影响半径，控制边界复杂度
两者都靠交叉验证来调。
