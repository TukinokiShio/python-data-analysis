① 高维数据的危机：OLS 为何会失效？

本页定位：这是全课的"问题定义"页。正则化不是凭空而来的技巧——它是 OLS 在三个层面同时崩塌后的必然回应。我们用"解方程 → 矩阵谱结构 → 抽样分布 → 预测表现"四个视角，把失效机制彻底讲清楚。

1.1 视角一：从正规方程看失效的两种模式

OLS 的解由正规方程（Normal Equations）给出：

\[ X^{T}X\,\widehat{\boldsymbol\beta}=X^{T}Y \qquad\Longleftrightarrow\qquad \widehat{\boldsymbol\beta}_{\text{OLS}}=\big(X^{T}X\big)^{-1}X^{T}Y\ \ (\text{若逆存在}) \]

方程是否有唯一解，完全取决于矩阵 \(X^{T}X\) 是否满秩。而 \(\operatorname{rank}(X^{T}X)=\operatorname{rank}(X)\le\min(n,p)\)，于是有两种失效模式：

🔴 模式 A：秩亏（p ≥ n）——"解根本不存在（不唯一）"

当 \(p>n\)：\(\operatorname{rank}(X)\le n<p\)，矩阵 \(X^{T}X\) 是 \(p\times p\) 的秩亏矩阵，行列式为 0，逆不存在。正规方程有无穷多解。

🟠 模式 B：近奇异（p < n 但共线）——"解存在但极不稳定"

当 \(p<n\) 但某些特征近似线性相关：\(X^{T}X\) 可逆，但最小特征值接近 0，逆矩阵元素巨大 → 解在数值上和统计上都极不稳定。

秩亏的几何意义：为什么"无穷多解"等于"每个解都不可信"？

把 \(X\) 的列看作 \(\mathbb{R}^n\) 中的 \(p\) 个向量。它们最多张成一个 \(\min(n,p)\) 维的子空间（列空间）。若 \(\widehat{\boldsymbol\beta}^{(1)}\)、\(\widehat{\boldsymbol\beta}^{(2)}\) 是两个不同的解，则

\[ X\widehat{\boldsymbol\beta}^{(1)}=X\widehat{\boldsymbol\beta}^{(2)}=\widehat Y \;\Longrightarrow\; X\big(\widehat{\boldsymbol\beta}^{(1)}-\widehat{\boldsymbol\beta}^{(2)}\big)=\mathbf 0 \;\Longrightarrow\; \text{差向量落在 } X \text{ 的零空间 } \mathcal N(X) \text{ 中} \]

\(\dim\mathcal N(X)=p-\operatorname{rank}(X)\ge p-n>0\)。也就是说：零空间里任意方向的扰动都不会改变拟合值——无穷多个解给出完全相同的 \(\widehat Y\) 和相同的 RSS。最小二乘准则"一视同仁"，数据中没有任何信息能帮助我们在它们之间做出选择。此时任何单一解都不可信——必须有外部准则来"补做决定"，这正是正则化（以及第 ⑨ 页 PCR/PLS 降维）所扮演的角色。

1.2 视角二：SVD 解剖——方差爆炸的精确机制

对 \(X\) 做奇异值分解 \(X=UDV^{T}\)，OLS 解与其协方差可以写成极醒目的形式：

\[ \widehat{\boldsymbol\beta}_{\text{OLS}}=\big(X^{T}X\big)^{-1}X^{T}Y=VD^{-1}U^{T}Y=\sum_{j=1}^{p}\underbrace{\frac{u_j^{T}Y}{d_j}}_{\text{要"除以 } d_j\text{" 的数}}\,v_j \qquad \operatorname{Var}\!\left(\widehat{\boldsymbol\beta}_{\text{OLS}}\right)=\sigma^{2}VD^{-2}V^{T}=\sigma^{2}\sum_{j=1}^{p}\frac{1}{d_j^{2}}\,v_j v_j^{T} \]

两个公式对照着看，机制一目了然：

  • 拟合值层面是安全的：\(\widehat Y=UU^TY=\sum_j (u_j^TY)\,u_j\)——只投影，没有任何除法，所以训练拟合永远"看起来很好"；
  • 系数层面是危险的：要还原出系数，每个方向必须除以 \(d_j\)。在小奇异值方向 \(d_j\to 0\) 上，分子 \(u_j^TY\) 几乎只是噪声水平（该方向没有真实信号），却被除以一个接近零的数——噪声被放大成百上千倍；
  • 方差公式精确记录了放大倍数：\(1/d_j^2\)。只要有一个 \(d_j\) 接近 0，总方差就爆炸。共线性越严重，最小奇异值越小，爆炸越剧烈。
一句话总结失效链条：训练误差只看投影（安全）→ 但我们关心的是系数/预测（要除 \(d_j\)，危险）→ 新数据的噪声实现不同，\(\widehat\beta\) 剧烈抖动 → 对新样本的预测失败。这就是"低训练误差 + 高测试误差"的矩阵级解释。

🧪 交互实验 A：共线性如何"吹大"方差（2 特征 VIF 特例）

两特征情形是上面的特例：\(X^TX\) 的特征值为 \(1\pm\rho\)，由 \(\operatorname{Var}(\hat\beta)=\sigma^2 V\,\mathrm{diag}\big(\tfrac{1}{1+\rho},\tfrac{1}{1-\rho}\big)V^T\) 可得

\[ \operatorname{Var}(\hat\beta_j)=\frac{\sigma^{2}}{n}\cdot\frac{1}{1-\rho^{2}} \qquad\text{（方差膨胀因子 } \mathrm{VIF}=\tfrac{1}{1-\rho^{2}}\text{）} \]

噪声特征总数 p = 10　（含 3 个真实特征，n = 40）
  • 训练 \(R^2\) 单调上升：即便全是噪声变量，OLS 也能找到"碰巧相关"的方向，把训练误差越压越低——当 \(p=n-1\) 时甚至能精确插值（训练 \(R^2=1\)）；
  • 测试 MSE 先平后爆：真实系数为 0 的噪声方向在训练集上被估计出非零系数（上一节讲的除以 \(d_j\) 的放大效应），这些纯噪声系数在新数据上造成纯粹的损害；
  • 背离点就在 \(p\approx n\) 附近：训练指标与测试指标背道而驰的程度，正是"过拟合"的可视化定义。

1.5 偏差-方差权衡：失效问题的理论收束

现在可以给"失效"一个精确的量化刻画。估计量的期望均方误差分解为：

\[ \operatorname{MSE}\!\left(\widehat{\boldsymbol\beta}\right) =\mathbb{E}\!\left[\left\|\widehat{\boldsymbol\beta}-\boldsymbol\beta\right\|^{2}\right] =\underbrace{\operatorname{Bias}\!\left(\widehat{\boldsymbol\beta}\right)^{2}}_{\text{偏差}^2} +\underbrace{\operatorname{Var}\!\left(\widehat{\boldsymbol\beta}\right)}_{\text{方差}} \]

OLS 的问题是：Bias \(=0\)（无偏），但由 1.2 节可知 Var 项里藏着 \(\sum_j 1/d_j^2\)——高维/共线下这一项失控，MSE 被方差彻底主导。治理思路只能是：主动放弃一部分无偏性（引入可控的小偏差），去交换方差的大幅下降。

正则化核心思想 💡
与其坚持绝对无偏但付出巨大方差，不如在目标函数中加入一个收缩惩罚项（Shrinkage Penalty）：牺牲一小部分无偏性（引入微小 Bias），换取方差的大幅下降，从而显著降低整体 MSE。接下来的 Ridge 与 Lasso，就是这个思想的两种具体实现。
🤔 课堂快问 1：OLS 在 p > n 时为什么"无解"？从秩的角度一句话说明。

因为 \(\operatorname{rank}(X^T X)=\operatorname{rank}(X)\le n < p\)，\(X^T X\) 是 \(p\times p\) 的秩亏矩阵，行列式为 0，逆矩阵不存在，正规方程有无穷多解。

🤔 课堂快问 2：拟合值 \(\widehat Y\) 的计算里没有任何除法，为什么系数 \(\widehat\beta\) 却会爆炸？

\(\widehat Y=UU^TY\) 只做投影，但把系数"翻译"回 \(p\) 维特征空间时必须除以各主方向的奇异值：\(\hat\beta=\sum_j (u_j^TY/d_j)v_j\)。小 \(d_j\) 方向上的噪声投影 \(u_j^TY\) 被近零数除 → 系数在该方向剧烈放大，方差贡献 \(\sigma^2/d_j^2\)。

🤔 课堂快问 3：交互实验 C 中，为什么加入与 y 无关的噪声特征反而让训练 \(R^2\) 上升？这些特征的真实系数是多少？

真实系数是 0。但 OLS 不知道这一点——它在噪声中"碰巧"找到了与训练集 y 相关的方向并赋予非零系数（方差项 \(\sigma^2/d_j^2\) 越大，这种假结构越夸张）。训练误差因此下降，但对新数据是纯损害 → 测试 MSE 上升。这正是需要"惩罚大系数"的根本原因。

② 岭回归（Ridge）：目标函数与矩阵求导

本页目标：建立 Ridge 目标函数，并在黑板上（此处为逐步点击展开）完成矩阵求导 → 一阶条件 → 闭合解的完整推导。

2.1 重要前提：必须先标准化

⚠️ 为什么正则化前必须标准化？ 惩罚项 \(\sum\beta_j^2\) 或 \(\sum|\beta_j|\) 默认所有系数"地位平等"。若某变量量纲大（如收入以"元"计）、其系数天然很小，几乎不受惩罚；量纲小的变量（如 0~1 变量）却会被过度压缩 → 惩罚强度被量纲绑架。因此对每个特征做 Z-score 标准化： \[ x_{ij}\leftarrow\frac{x_{ij}-\bar x_j}{s_j}\quad(\text{均值 }0,\text{方差 }1),\qquad y_i\leftarrow y_i-\bar y\ (\text{省略截距项}) \]

2.2 Ridge 目标函数

\[ \begin{aligned} RSS_{\text{Ridge}}(\boldsymbol\beta) &=\sum_{i=1}^{n}\Big(y_i-\sum_{j=1}^{p}x_{ij}\beta_j\Big)^{2}+\lambda\sum_{j=1}^{p}\beta_j^{2}\\ &=(Y-X\boldsymbol\beta)^{T}(Y-X\boldsymbol\beta)+\lambda\,\boldsymbol\beta^{T}\boldsymbol\beta \end{aligned} \]

其中 \(\lambda\ge 0\) 是调节参数（超参数）：

  • \(\lambda = 0\)：退化为经典 OLS；
  • \(\lambda \to \infty\)：惩罚项主导，\(\widehat{\boldsymbol\beta}_{\text{Ridge}}\to \mathbf{0}\)（所有系数被压向 0，但永不精确等于 0）。

2.3 矩阵求导四步推导 黑板重点

点击下方按钮，逐步展开完整推导（每步都注明所用向量求导法则）：

第 1 步 · 展开目标函数
\[RSS_{\text{Ridge}}(\boldsymbol\beta)=Y^{T}Y-2\boldsymbol\beta^{T}X^{T}Y+\boldsymbol\beta^{T}X^{T}X\boldsymbol\beta+\lambda\boldsymbol\beta^{T}\boldsymbol\beta\]

展开 \((Y-X\beta)^T(Y-X\beta)=Y^TY-Y^TX\beta-\beta^TX^TY+\beta^TX^TX\beta\)，注意标量 \(Y^TX\beta=\beta^TX^TY\)，合并同类项。

第 2 步 · 对 β 求梯度

利用向量求导法则（\(A\) 对称时）：\(\nabla_{\beta}(\beta^T A\beta)=2A\beta\)，\(\nabla_{\beta}(a^T\beta)=a\)。

\[\nabla_{\boldsymbol\beta}RSS_{\text{Ridge}}=-2X^{T}Y+2X^{T}X\boldsymbol\beta+2\lambda\boldsymbol\beta\]
第 3 步 · 一阶条件（令梯度为零）
\[-2X^{T}Y+2\big(X^{T}X+\lambda I\big)\boldsymbol\beta=\mathbf{0}\;\Longrightarrow\;\big(X^{T}X+\lambda I\big)\boldsymbol\beta=X^{T}Y\]
第 4 步 · 闭合解（Closed-form）
\[\boxed{\;\widehat{\boldsymbol\beta}_{\text{Ridge}}=\big(X^{T}X+\lambda I\big)^{-1}X^{T}Y\;}\]

与 OLS 解相比，只多了一个 \(\lambda I\)——但这"一点点"让矩阵永远可逆（下一页证明），也实现了方差收缩。

✔ 推导完成

🔍 几何视角：Ridge = 在系数空间加一个"弹簧势能"

把 \(\lambda\|\beta\|^2\) 想象成把系数拴在原点的弹簧：λ 越大，弹簧越紧，解被拉得越靠近原点。代价函数曲面（碗状）与弹簧的合力最低点，就是岭回归解。

等价的约束形式（拉格朗日对偶）：

\[\min_{\boldsymbol\beta}\ \sum_{i=1}^n\Big(y_i-\sum_j x_{ij}\beta_j\Big)^2\quad \text{s.t.}\quad \sum_j\beta_j^2\le s\]

λ 与 s 一一对应（λ 越大 ⇔ s 越小）。

Ridge 解 = 等高线与 L2 约束圆盘的切点

🤔 课堂快问：λ→∞ 时 Ridge 系数趋向什么？会不会精确等于 0？

趋向 \(\mathbf 0\)，但不会精确等于 0。闭合解 \(\hat\beta_{\text{Ridge}}=(X^TX+\lambda I)^{-1}X^TY\) 中只要 \(X^TY\neq\mathbf 0\)，对任意有限的 λ，解都是非零的。这与 Lasso 的"精确归零"形成关键对比（第 ④、⑥ 页）。

③ 数学本质：可逆性证明、SVD 收缩与正交特例

3.1 为什么 \(X^{T}X+\lambda I\) 必定可逆？黑板重点

点击下方展开两种证法：

证法 A · 特征值论证

① \(X^TX\) 是半正定矩阵，所有特征值 \(\mu_j\ge 0\)；
② 加入 \(\lambda I\)（\(\lambda>0\)）后，特征值变为 \(\mu_j+\lambda>0\)；
③ 所有特征值严格大于 0 ⇒ \(X^TX+\lambda I\) 是严格正定矩阵；
④ 行列式 \(\det=\prod_j(\mu_j+\lambda)>0\)，故永远可逆——即使 \(p>n\) 时也如此！

\[\widehat{\boldsymbol\beta}_{\text{Ridge}}\ \text{在任意维度下都存在且唯一}\]
证法 B · 二次型直接证明（与课后作业呼应）

任取非零向量 \(\mathbf v\neq\mathbf 0\)：

\[ \mathbf v^{T}\big(X^{T}X+\lambda I\big)\mathbf v =\underbrace{\mathbf v^{T}X^{T}X\mathbf v}_{=\|X\mathbf v\|^{2}\ge 0}+\lambda\,\underbrace{\mathbf v^{T}\mathbf v}_{=\|\mathbf v\|^{2}>0}>0 \]

二次型恒正 ⇒ 严格正定 ⇒ 可逆。若进一步 \(X\) 列满秩，则 \(\|Xv\|^2>0\) 也严格成立。

3.2 SVD 视角：岭回归是在"按主成分缩放"投影

对 \(X\) 做奇异值分解 \(X=UDV^{T}\)（\(D=\operatorname{diag}(d_1,\dots,d_p)\) 为奇异值，\(d_1\ge d_2\ge\cdots\)），则两种方法的拟合值为：

\[ \widehat Y_{\text{OLS}}=UU^{T}Y=\sum_{j=1}^{p}u_j u_j^{T}Y, \qquad \widehat Y_{\text{Ridge}}=\sum_{j=1}^{p}\underbrace{\frac{d_j^{2}}{d_j^{2}+\lambda}}_{\text{收缩因子 }<1}\,u_j u_j^{T}Y \]

📉 交互图：收缩因子 \(d_j^2/(d_j^2+\lambda)\) 随奇异值的变化

拖动 λ：变异巨大（d² 大）的主成分方向几乎不缩减（因子→1）；变异极小、方差巨大的方向被强力压向 0。

λ = 1.0
解读：岭回归的聪明之处——信息丰富的方向（大 d）几乎原样保留，噪声主导的方向（小 d，正对应共线/高方差方向）被猛烈压缩。这就是"以微小偏差换巨大方差下降"的精确数学表达。

3.3 正交设计下的特例

若特征完全正交 \(X^{T}X=I\)，闭合解立即退化为一维缩放：

\[ \big(I+\lambda I\big)^{-1}X^TY=\frac{1}{1+\lambda}\widehat{\boldsymbol\beta}_{\text{OLS}} \quad\Longrightarrow\quad \hat\beta_{j,\text{Ridge}}=\frac{1}{1+\lambda}\,\hat\beta_{j,\text{OLS}} \]

所有系数按同一比例 \(1/(1+\lambda)\) 整体缩减——但永远不会缩减到精确 0。记住这个结论，下一页看 Lasso 在同一场景下的截然不同表现。

🎚️ 交互：正交设计下 Ridge 的等比收缩

λ = 0.0　→　缩放因子 1/(1+λ) = 1.000
🤔 课堂快问：收缩因子何时接近 1？何时接近 0？分别对应什么样的主成分方向？

当 \(d_j^2\gg\lambda\) 时因子 \(\to 1\)（数据在该方向变异大、信息丰富，保留）；当 \(d_j^2\ll\lambda\) 时因子 \(\to 0\)（该方向变异小、方差大、多为噪声或共线方向，压制）。

④ Lasso：为什么 L1 的"菱形尖角"能选出特征？

4.1 Lasso 目标函数

\[ \begin{aligned} RSS_{\text{Lasso}}(\boldsymbol\beta) &=\sum_{i=1}^{n}\Big(y_i-\sum_{j=1}^{p}x_{ij}\beta_j\Big)^{2}+\lambda\sum_{j=1}^{p}\left|\beta_j\right|\\ &=(Y-X\boldsymbol\beta)^{T}(Y-X\boldsymbol\beta)+\lambda\,\|\boldsymbol\beta\|_{1} \end{aligned} \]
⚠️ 关键难点也是关键机遇：\(L_1\) 范数 \(\|\beta\|_1=\sum_j|\beta_j|\) 在 \(\beta_j=0\) 处不可微——普通微分求导失效；但正是这一个个"尖角"赋予了 Lasso 生成稀疏解（不重要系数被精确压为 0）的能力。

4.2 约束等价形式

\[ \min_{\boldsymbol\beta}\ \sum_{i=1}^n\Big(y_i-\sum_j x_{ij}\beta_j\Big)^2 \quad\text{s.t.}\quad \begin{cases} \sum_j \beta_j^2\le s & (\text{Ridge})\\[4pt] \sum_j |\beta_j|\le s & (\text{Lasso}) \end{cases} \]

几何图景：RSS 的等高线是以 \(\widehat{\boldsymbol\beta}_{\text{OLS}}\) 为中心的同心椭圆，向外扩张；约束域是一朵以原点为中心的"边界墙"。解 = 椭圆与墙首次接触的切点。切点落在哪，决定了是否出现 0 系数。

4.3 读图结论 黑板图解重点

🔵 Ridge：L2 圆形约束

圆周平滑无棱角。椭圆扩张时切点几乎总落在圆周的"一般位置"——\(\hat\beta_1,\hat\beta_2\) 都不为 0。系数被整体缩小，但一个都不淘汰。→ 不做特征选择。

🔴 Lasso：L1 菱形约束

菱形的四个尖角恰好落在坐标轴上 \((\pm s,0),(0,\pm s)\)。椭圆向外扩张时，极大概率最先撞上某个尖角——切点位于坐标轴 ⇒ 一个系数被精确压为 0！→ 自动完成特征选择。

直觉总结：L1 约束域是"带尖刺的"，尖刺方向恰为坐标轴——高维时尖角/棱边极多，RSS 等高线极易先在棱上相切 ⇒ 大量系数被精确归零，产生稀疏模型。
🤔 课堂快问：为什么 L1 在坐标轴上有"尖角"，而 L2 没有？这和 |x| 与 x² 的图像有什么关系？

\(|x|\) 在 0 处是一个"V"形尖点（左导数 −1，右导数 +1，不可微）；\(x^2\) 在 0 处平滑（导数为 0）。二维约束边界 \(|β₁|+|β₂|=s\) 在各坐标轴处正是由这样的 V 形尖点构成；而 \(β₁²+β₂²=s²\) 处处光滑。不可微的"尖"把最优解"钉"在轴上 ⇒ 出现精确的 0。

⑤ 软门限算子：Lasso 稀疏解的代数证明

本页在正交设计（\(X^TX=I\)）假设下，完整推导 Lasso 解的显式公式，揭示"平移 + 截断"的归零机制。

5.1 问题化简

正交设计下，各维解耦，逐分量求解同一问题：

\[ Q(\beta)=\frac{1}{2}\big(\hat\beta_{\text{OLS}}-\beta\big)^{2}+\lambda\,|\beta| \qquad\text{（一维凸优化，β=0 处不可微 ⇒ 分类讨论）} \]

点击下方按钮逐步展开三段分类讨论：

情形 ① β > 0

此时 \(|\beta|=\beta\)，函数可微：

\[\frac{dQ}{d\beta}=-\big(\hat\beta_{\text{OLS}}-\beta\big)+\lambda=0\;\Longrightarrow\;\beta=\hat\beta_{\text{OLS}}-\lambda\]

此解合法当且仅当 \(\hat\beta_{\text{OLS}}-\lambda>0\)，即 \(\hat\beta_{\text{OLS}}>\lambda\)。直观：OLS 估计先向 0 平移 λ。

情形 ② β < 0

此时 \(|\beta|=-\beta\)：

\[\frac{dQ}{d\beta}=-\big(\hat\beta_{\text{OLS}}-\beta\big)-\lambda=0\;\Longrightarrow\;\beta=\hat\beta_{\text{OLS}}+\lambda\]

合法条件：\(\hat\beta_{\text{OLS}}+\lambda<0\)，即 \(\hat\beta_{\text{OLS}}<-\lambda\)。同样是向 0 平移 λ。

情形 ③ |β̂_OLS| ≤ λ

①②均不合法 ⇒ 极值只能在不可微点 \(\beta=0\) 处取得。用次梯度验证：0 属于 \(Q\) 在 0 点的次微分集 \(\big[-\hat\beta_{\text{OLS}}-\lambda,\;-\hat\beta_{\text{OLS}}+\lambda\big]\)（当 \(|\hat\beta_{\text{OLS}}|\le\lambda\) 时该区间包含 0）。故最优解 \(\beta=0\)——被"门限"截断归零。

合并：软门限算子（Soft-Thresholding Operator）
\[ \hat\beta_{j,\text{Lasso}}=S_{\lambda}\big(\hat\beta_{j,\text{OLS}}\big) =\operatorname{sign}\big(\hat\beta_{j,\text{OLS}}\big)\max\Big(0,\;\big|\hat\beta_{j,\text{OLS}}\big|-\lambda\Big) \] \[ =\begin{cases} \hat\beta_{j,\text{OLS}}-\lambda, & \hat\beta_{j,\text{OLS}}>\lambda\\ 0, & \big|\hat\beta_{j,\text{OLS}}\big|\le\lambda\\ \hat\beta_{j,\text{OLS}}+\lambda, & \hat\beta_{j,\text{OLS}}<-\lambda \end{cases} \]

名字由来：图像像被"削平"的门限——中间一段被压成 0，两段保留部分被向 0 平移 λ（"软"指过渡是连续的）。

✔ 推导完成

🎚️ 交互：软门限算子 \(S_\lambda(\cdot)\) 工作实况

门限 λ = 0.60
观测到的 OLS 系数 β̂ = 1.30

5.2 三种缩减机制对比

方法正交设计下的解机制会产生精确 0 吗？
OLS\(\hat\beta_{\text{OLS}}\)恒等映射，不缩减❌
Ridge\(\dfrac{1}{1+\lambda}\hat\beta_{\text{OLS}}\)硬缩放：全体等比例缩小❌（任意有限 λ 均非零）
Lasso\(S_\lambda(\hat\beta_{\text{OLS}})\)平移 λ + 截断归零✅（\(|β̂|≤λ\) 时精确为 0）

⑥ 正交设计全景：OLS / Ridge / Lasso 系数对照实验

用一个 6 特征的数值实验，把上一页的三个公式"演"出来。设真实的 OLS 估计为：

\[ \hat\beta_{\text{OLS}}=(\,1.20,\;0.80,\;-0.50,\;0.30,\;-0.15,\;0.05\,) \]

🎚️ 交互：拖动 λ，观察三个估计量如何加工这 6 个系数

λ = 0.40

6.1 观察要点

OLS（灰色）

纹丝不动。但它把 0.05 这种"噪声级"小系数也照单全收——高维下这些噪声会被放大。

Ridge（蓝色）

所有柱子按 1/(1+λ) 等比例变矮，"形状"不变。0.05 被缩小但永远剩一口气，6 个特征一个不少。

Lasso（红色）

大系数只是"矮一截"，但 |β̂|≤λ 的柱子整根消失。λ=0.4 时 X₅(−0.15)、X₆(0.05) 被精确归零 → 模型自动从 6 个特征筛到 4 个。

教学落点：Ridge 是"全员减薪"，Lasso 是"末位淘汰"。稀疏性带来的不只是预测，更是可解释性——这正是 Lasso 名字里 "Selection Operator" 的含义。
🤔 课堂快问：本例中 λ 超过多少时，Lasso 会把 X₄(0.30) 也淘汰掉？Ridge 在同样 λ 下会做什么？

λ ≥ 0.30 时 \(|0.30|-\lambda\le 0\)，X₄ 归零（X₅ 更早，λ≥0.15 时已被淘汰）；此时仅 X₁、X₂、X₃ 幸存。Ridge 则只是继续整体等比缩小，所有系数保持非零。

⑦ 弹性网、交叉验证与超参数选择

7.1 弹性网（Elastic Net）

\[ RSS_{\text{ElasticNet}}(\boldsymbol\beta)=RSS+\lambda_1\|\boldsymbol\beta\|_1+\lambda_2\|\boldsymbol\beta\|_2^2 \]

动机：当存在一组强相关特征时，Lasso 倾向于随机挑选其中一个、忽略其余，结果不稳定。加入 \(L_2\) 项后产生组效应（Group Effect）：相关特征被"打包"一起保留或一起压缩——兼具 Ridge 的稳定与 Lasso 的稀疏。（scikit-learn 中用 l1_ratio 参数混合两者。）

7.2 K 折交叉验证（K-Fold CV）选择 λ

\[ \operatorname{MSE}_{\text{CV}}(\lambda)=\frac{1}{K}\sum_{k=1}^{K}\operatorname{MSE}_k(\lambda), \qquad K=5\ \text{或}\ 10,\quad \lambda\in[10^{-4},10^{5}]\ (\text{对数等间隔网格}) \]

📉 交互：CV 曲线、λ.min 与 1-SE 法则

下图是一条典型的 Lasso CV 曲线（横轴 log λ，越大越收缩）。拖动浏览，观察两个候选点的位置：

标准 ① lambda.min

使 CV-MSE 绝对最小 的 λ。预测性能最好，但模型可能偏复杂（保留变量多），且对 CV 划分的随机性敏感。

标准 ② lambda.1se（一倍标准差法则）⭐

在 \(\operatorname{CV\text{-}MSE}_{\min}+\operatorname{SE}\) 范围内的最大 λ（即最简单、最稀疏的模型）。性能与最优解统计上无显著差异，却更稳健、更可解释——ISLR 推荐。

⑧ Python 实战：系数路径图与交叉验证

8.1 基于 scikit-learn 的全流程代码

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import RidgeCV, LassoCV, ElasticNetCV
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

# 1. 加载与预处理数据（Hitters 棒球薪资数据集）
df = pd.read_csv('Hitters.csv').dropna()
X = pd.get_dummies(df.drop(['Salary'], axis=1), drop_first=True)
y = df['Salary']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

# 2. 数据标准化 —— 正则化前的必须步骤！
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled  = scaler.transform(X_test)

# 3. LassoCV 拟合与 10 折交叉验证
alphas = np.logspace(-3, 3, 200)
lasso_cv = LassoCV(alphas=alphas, cv=10, max_iter=10000, random_state=42)
lasso_cv.fit(X_train_scaled, y_train)

print(f"最佳超参数 alpha (λ): {lasso_cv.alpha_:.4f}")
pred = lasso_cv.predict(X_test_scaled)
print(f"测试集 RMSE: {np.sqrt(mean_squared_error(y_test, pred)):.2f}")

# 4. 查看非零变量个数（特征选择结果）
coefs = pd.Series(lasso_cv.coef_, index=X.columns)
print("被保留的非零特征:")
print(coefs[coefs != 0])

⑨ 模型选型矩阵 与 课后作业

9.1 正则化与降维方法选型矩阵

模型惩罚类型 / 特征提取优势场景缺点 / 局限
OLS无惩罚低维、无严重共线性，追求无偏性高维或多重共线性下过拟合
Ridge\(L_2\) 范数 \(\sum\beta_j^2\)强多重共线性、所有变量均有微弱贡献不作特征选择，解释性较差
Lasso\(L_1\) 范数 \(\sum|\beta_j|\)大量冗余特征，追求稀疏解与变量筛选强相关特征组中表现不稳定
Elastic Net\(L_1+L_2\) 范数强相关特征组的高维数据需调优两个超参数 \(\alpha,\lambda\)
PCR / PLS投影至低维主成分变量极多、维度极高（如光谱数据）主成分的业务含义难解释

9.2 方法选择决策建议

🧭 快速决策：
① 变量数不多且无共线性 → OLS；
② 共线性强但认为所有变量都有贡献 → Ridge；
③ 想要稀疏可解释模型 / 做变量筛选 → Lasso；
④ 高维 + 存在强相关特征组 → Elastic Net（通常是最稳妥的起点）；
⑤ p ≫ n 且只关心预测、可牺牲可解释性 → PCR / PLS。
无论选哪个，超参数一律用 K 折交叉验证 + 1-SE 法则 确定。

9.3 课后作业 对应教案四

作业 1 · 推导题：证明正交设计下 \(\widehat{\boldsymbol\beta}_{\text{Ridge}}=\frac{1}{1+\lambda}\widehat{\boldsymbol\beta}_{\text{OLS}}\)

参考思路：把 \(X^TX=I\) 直接代入闭合解：\((I+\lambda I)^{-1}X^TY=\frac{1}{1+\lambda}I\cdot X^TY=\frac{1}{1+\lambda}(X^TX)^{-1}X^TY\)。

作业 2 · 证明题：证明任意 \(\lambda>0\) 时 \(X^TX+\lambda I\) 严格正定

参考思路：任意 \(\mathbf v\neq\mathbf0\)，\(\mathbf v^T(X^TX+\lambda I)\mathbf v=\|X\mathbf v\|^2+\lambda\|\mathbf v\|^2\ge\lambda\|\mathbf v\|^2>0\)（本课件第 ③ 页证法 B）。

作业 3 · 分析题：为什么正则化前必须 Z-score 标准化？不做的后果？

参考思路：惩罚项对各系数一视同仁；量纲大的变量系数天然偏小，几乎不受罚，量纲小的变量被过度压缩 → 惩罚强度被量纲"绑架"，正则化失去公平性。另：未中心化时截距项也会被误罚。
