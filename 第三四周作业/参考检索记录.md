# 参考检索与验证记录

## 检索目的与边界

作业要求涉及 Ridge/Lasso/Elastic Net 的交叉验证与 Netflix 评分数据来源。检索范围限定为课程给定课件、Kaggle 数据卡、ISLP 官方教材数据文档和 scikit-learn 官方 API 文档；没有复制第三方实现代码。

## 候选与选择

| 参考 | 来源与匹配 | 许可/处理 | 使用方式 |
|---|---|---|---|
| Netflix Prize data | [Kaggle 数据卡](https://www.kaggle.com/netflix-inc/netflix-prize-data/data) 描述用户-电影 1–5 星评分，并列出 17,770 个电影 ID、约 480,189 名用户；与 SVD 课件的 Netflix 评分矩阵例子匹配。数据卡指出原始数据包来自 [Internet Archive](https://archive.org/download/nf_prize_dataset.tar/nf_prize_dataset.tar.gz)。 | Kaggle 卡的许可标为 Other；不把压缩包或评分样本提交到 Git，只提交抽样规则、聚合结果和代码。 | 从原始包流式读取电影评分文件，对随机选出的电影抽样；对用户 ID、电影 ID 和评分时间建立 Elastic Net 回归特征。 |
| Hitters | [ISLP 官方 Hitters 文档](https://intro-stat-learning.github.io/ISLP/datasets/Hitters.html) 说明数据来自 1986–1987 年 MLB 球员记录，并提供 322×20 数据结构及 Salary 字段。 | 将 [Rdatasets CSV 镜像](https://vincentarelbundock.github.io/Rdatasets/csv/ISLR/Hitters.csv)保存为小型课程数据文件；未添加 ISLP 运行依赖。 | 用 Salary 非缺失的 263 条记录比较 RidgeCV、LassoCV 和 ElasticNetCV。 |
| scikit-learn 正则化 API | [ElasticNetCV 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNetCV.html) 说明 `l1_ratio` 控制 L1/L2 组合、`alpha` 控制惩罚强度，并支持交叉验证。 | 依赖版本按项目 `requirements.txt` 的最低版本风格声明；实际验证在项目 `.venv` 完成。 | 第三周按课件使用 RidgeCV/LassoCV/ElasticNetCV；第四周用包含折内预处理的 GridSearchCV 搜索 ElasticNet 参数。 |

## 验证记录

- Hitters 下载文件读取为 322 行、20 个有效字段；Salary 缺失 59 行。第三周脚本完成 10 折 CV、独立测试集评分和系数路径图生成。
- Netflix 原始压缩包 HTTP 下载成功，文件大小为 697,552,028 字节；外层 gzip tar 中含 `training_set.tar`。脚本成功从 150 部随机电影生成 14,727 条评分样本，并完成 5 折参数搜索与测试集评价。
- 项目环境：Python 3.12.4、NumPy 2.5.3、pandas 3.0.6、scikit-learn 1.9.1、Matplotlib 3.11.2、statsmodels 0.15.0。
- 实际运行结果分别记录于 [第三周模型比较结果.csv](第三周模型比较结果.csv) 和 [第四周Netflix模型结果.csv](第四周Netflix模型结果.csv)；分析边界与抽样影响见对应作业答案。

## 未验证事项

- Netflix 的测试指标来自 150 部电影、每部最多 100 条评分的平衡样本，不代表完整竞赛数据的总体性能；完整规模复验成本较高，当前未执行。
- Kaggle 数据卡将许可标为 Other，原始评分数据的再分发权利未进一步确认。因此原始包和本地抽样文件均排除在 Git 提交之外。
